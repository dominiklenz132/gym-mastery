# Design assets and UI foundations

UI components follow adapted shadcn/ui New York (Radix) patterns: https://github.com/shadcn-ui/ui (MIT, Copyright shadcn). Radix, React, Lucide, Tailwind and other package license details are included in their npm distributions; exact versions are pinned in package-lock.json.

Gym photograph: https://images.unsplash.com/photo-1534438327276-14e5300c3a48 — Unsplash image photo-1534438327276-14e5300c3a48. Used under the Unsplash license: https://unsplash.com/license. Bundled locally for runtime independence.

Fonts Manrope and DM Sans are loaded from Google Fonts; both use the SIL Open Font License. The application remains usable with local system font fallbacks.
