# Training QA — 25 October 2026

Scope: the requested 30-minute test window, starting 07:08:25 UTC. All write tests used the loopback-only isolated QA account and in-memory database, never the production user's training history. Production checks are read-only.

## Fixed

- Exercise outline could remain sticky over a later full-width pause row. Removed sticky positioning; timer and controls remain bounded by their own card.
- Shared exercise performances derive from actual stored sets across all plans, including an active session. Comparison normalizes Unicode, case and whitespace, not distinct exercise variants.
- Both weight and repetitions are prefilled from the latest set. Plan detail views and MCP plan reads expose the same latest performance. Existing histories and plan snapshots are not rewritten.
- Correcting the latest set updates the shared performance; correcting an older set does not override a newer performance.
- Live data refresh now continues during training and refreshes on returning to the app, without overwriting an edited draft or forcing an unexpected exercise change.
- Explicit action locking and stable request identifiers prevent duplicate saves during retries. After a lost success response, a retry recognizes an already saved set.
- Pause presets, custom 0–1800 seconds and an off switch persist to the account. The last enabled duration is remembered. A deadline-based countdown survives reload/navigation and catches up after backgrounding. Completed timers stop scheduling updates; countdown updates do not rerender the whole workout.
- Added in-session set correction and explicit confirmation before completing a workout.
- Progression uses the same exercise from a previous completed plan when the current exercise has no sets, rejects mixed units and holds inconsistent work-set weights. Suggestions are cleared when the underlying performance changes.

## Limits

Real phone sleep/browser throttling, native ChatGPT draft handling, full screen-reader audit and commercial backup/restore operations remain outside this test window.
